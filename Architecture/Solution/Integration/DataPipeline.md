# Data Pipeline

---

## Purpose

This document describes how data moves through the Phoenix platform.

Unlike the Layer Architecture, the Pipeline represents runtime execution.

---

# Processing Pipeline

```
External Source

↓

Import

↓

Validation

↓

Transformation

↓

DailyMarketData

↓

TradingUniverse

↓

Indicator Engine

↓

Feature Engine

↓

Prediction Engine

↓

Signal Engine

↓

Portfolio Engine

↓

Backtest Engine

↓

Reporting
```

---

## Pipeline Rules

Every stage shall have a single responsibility.

Each stage receives immutable input.

Each stage produces independent output.

Pipeline stages shall remain replaceable.

No stage shall modify outputs generated by previous stages.
