| Term       | Definition                                     |
| ---------- | ---------------------------------------------- |
| Market     | یک بازار مالی مانند بورس ایران یا بازار رمزارز |
| Exchange   | محل انجام معاملات در یک Market                 |
| Instrument | هر دارایی قابل معامله                          |
| Symbol     | شناسه معاملاتی یک Instrument                   |
| Price      | داده خام قیمت                                  |
| Indicator  | خروجی محاسبات تکنیکال بر پایه داده خام         |
| Feature    | ورودی مدل‌های آماری یا یادگیری ماشین           |
| Signal     | پیشنهاد خرید، فروش یا نگهداری                  |
| Position   | وضعیت یک معامله باز                            |
| Trade      | نتیجه کامل یک معامله از ورود تا خروج           |
