# 1. Purpose

This document defines the official architectural baseline of the Phoenix Platform repository.

It identifies the canonical architectural assets that collectively constitute the Architecture Baseline Version 2026.1.

Future architectural evolution shall proceed from this baseline.

# 5. Baseline Principles

The following principles define this baseline:

- Canonical artifacts are the single source of truth.
- Enterprise diagrams are derived artifacts.
- Repository evolution shall be controlled through ADRs.
- Architectural governance is mandatory.

---

# 6. Evolution Policy

This baseline may evolve only through:

- Approved ADRs
- Approved Governance Reviews
- Approved Repository Audits
